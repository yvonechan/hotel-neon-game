## Task clarity changes

Every chapter now shows the task wording at submission, with direct links to available source records. Questions identify their source and expected answer type. Required fields and format placeholders prevent empty submissions. Chapter 5 explicitly refers back to the Chapter 1 charging-cradle sensor event.

The finale replaces manual evidence classification with six concrete discussion questions and automatically attaches inspected records. Each question needs at least one inspected supporting source; the four deduction answers remain checked by the engine. This removes the memory/classification hurdle without removing the evidence gate.

## Discovery rules

All revealed case records are accessible in grouped map files without opening the quest log. The repeatable reception hint introduces honey toast; mentioning honey in English or Japanese opens KUMA's source tray for the whole room. Before that, source and document-ID requests do not expose the underlying originals. The food phrase is a scripted narrative event, not a prompt-injection mitigation.

The file index search is a static fictional search, not shell access. It finds an absolute storage path; the public file viewer accepts a relative path, so players still work out the traversal. Only the final optional hint gives the full traversal answer. Private observations remain private until shared.

## Verification limits

Automated checks cover bilingual rendering, evidence-group agreement, task gates, state transitions, image packaging and Worker/WebSocket behavior. Visual browser, mobile and blind-playtest validation remain outstanding.
